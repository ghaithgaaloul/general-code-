# Hardware

## Arduino
- Arduino Nano/Uno
- Potentiometer
- Relay
- Servo
- 28BYJ-48 + ULN2003
- MQ-series gas sensor
- HC-SR04

- ESP32 DevKit
- Potentiometer
- Relay
- Servo
- 28BYJ-48 + ULN2003
- MQ-series gas sensor
- HC-SR04

Motors and relay loads require suitable external power/driver hardware.
